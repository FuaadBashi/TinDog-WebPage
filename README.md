# TinDog — Responsive Landing Page

A static landing-page exercise for a fictional dog-dating product, built with HTML, CSS, and Bootstrap 5.

## Preview locally

```bash
git clone https://github.com/FuaadBashi/TinDog-WebPage.git
cd TinDog-WebPage
python3 -m http.server 8000
```

Open [localhost:8000](http://localhost:8000), or open `index.html` directly in a browser. No Node build step is required.

## Code to explore

- [index.html](index.html): hero, features, testimonials, pricing, and footer.
- [style.css](style.css): custom styling and gradient animation.
- [Images](Images): local imagery and icons.

Resize the browser to inspect the layout at mobile and desktop widths. This repository implements a promotional page; app-store buttons and pricing content do not establish a working dating service.
